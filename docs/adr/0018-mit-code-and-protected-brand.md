# ADR 0018: Publish MIT code under a protected product brand

## Status

Accepted

## Context

SnapSlot is an independent screenshot-inbox tool inspired by a broad interaction pattern also used by other tools. It needs community trust and an unambiguous identity of its own. Dryline and 晒图绳 have been rejected as product names.

## Decision

Release SnapSlot's source code under the MIT license. Retain rights to the SnapSlot and 快照槽 names, icon, and website visual identity. Use original brand assets rather than names or graphics from related products. Use the original Pixel Rail rather than a rope, metallic clip, hanging-card, or pegboard motif.

## Consequences

The project can accept and share code openly while preserving a distinct product identity. The repository and website need a clear trademark/brand-not-granted notice alongside the MIT code license. The generated concept is an art-direction reference and must be recreated as a clean vector master before release.
