# ADR 0009: Use a Fluent shell with a tactile clothesline

## Status

Accepted

## Context

The product needs a memorable visual identity without compromising its place in the Windows desktop. A fully skeuomorphic application would extend the clothesline metaphor into settings and conventional controls, while a wholly generic Fluent interface would lose the product's central visual idea.

## Decision

Use Windows Fluent styling for standard application surfaces, such as settings, menus, and controls. Reserve warm material, physical depth, and object-like rendering for the clothesline, clips, and screenshot cards.

## Consequences

The clothesline becomes the distinctive visual focus while standard UI stays familiar and accessible to Windows users. The visual system has two deliberate layers that must share typography, contrast, and color tokens.
