# SnapSlot v1.1.0

本版改进快捷键设置、设置窗口和便签自动收起体验。

- macOS 与 Windows 继续通过按键录入快捷键。仅暂停 SnapSlot 自己的快捷键，其他应用和系统快捷键保持可用；macOS 录入无需辅助功能权限。
- 启动、打开设置及开始录入时同时检查两组快捷键，提前显示检测到的冲突与实际生效的替代组合。编辑期间保留警告，修改一组不会覆盖另一组刚更新的结果。
- macOS 额外检查已启用的系统快捷键。部分应用使用共享快捷键注册，系统可能无法报告此类冲突。收取其他应用中选中的文字仍需要辅助功能权限。
- 修复设置窗口最小化后的恢复、置前和拖动交互；打开设置不再影响便签的上沿唤出及鼠标离开收起。
- 改进 Windows 托盘和设置窗口初始化，修复新便签入场动画重复播放、固定状态标记等问题。
- 同步六语言 README、设置截图、引导截图、宣传截图和 GIF / MP4 演示录屏。

| 下载包 | 适用系统 | 安装方式 |
| --- | --- | --- |
| `SnapSlot-1.1.0-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel | 打开 DMG，将 SnapSlot 拖入“应用程序” |
| `SnapSlot-1.1.0-windows-x64-setup.exe` | Windows 10 / 11 x64 | 双击 Setup 安装；安装后从桌面或开始菜单打开 |

官网与 GitHub Release 提供相同安装包，随附 `SHA256SUMS.txt` 和 `manifest.json`。历史版本保留在 GitHub Releases，官网源码仅保留最新安装包目录。

Mac 包使用 ad-hoc 签名，尚未取得 Developer ID 签名和 Apple 公证；Windows 包未做代码签名。Windows 安装器包含 .NET 运行时，缺少 WebView2 时会从微软官方地址联网安装。

发布验证包括 Mac 双架构编译、原生窗口冒烟检查和 DMG 完整性，Windows 逻辑检查、自包含编译与安装器逐文件校验，以及网站、原生界面和下载 HTTP 回归。标签发布工作流还验证 Windows 安装、版本、快捷方式、原生界面和卸载，并复验 Mac 双架构与签名。
