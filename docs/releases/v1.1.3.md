# SnapSlot v1.1.3

这一版为官网分发的 Mac 包接入 Developer ID 签名和 Apple 公证，并修复 Windows 打开官网时先闪过 Mac 演示及下载选项的问题。

- Mac 应用使用 Developer ID Application 证书签名，启用 Hardened Runtime 和安全时间戳；应用及最终 DMG 均经 Apple 公证并附加票据，通过签名、票据及 Gatekeeper 检查后才允许发布。macOS 仍可能要求确认首次打开。
- 官网演示和下载区在确认系统后再显示，首次可见即匹配当前系统。保留用户手动选择的下载版本，并维持键盘切换和手机布局。
- 禁用 JavaScript 时仍可直接选择两端下载入口。

| 下载包 | 适用系统 |
| --- | --- |
| `SnapSlot-1.1.3-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel |
| `SnapSlot-1.1.3-windows-x64-setup.exe` | Windows 10 1809+ / 11，x64 |

随附 SHA-256、记录实际签名及公证 submission ID 的安装包清单、完整静态官网与六语言媒体 ZIP。Windows 继续包含 .NET，缺少 WebView2 时由安装器从微软下载；Windows 安装包仍未做代码签名。

发布流水线在 GitHub runner 执行双端构建、Mac 公证与原生冒烟检查、Windows 安装和卸载验证、官网及共享界面回归，并刷新六语言媒体。证书或公证授权缺失、Apple 拒绝、验证失败时停止发布，不回退到临时签名，不覆盖历史版本。
