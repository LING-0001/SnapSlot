# SnapSlot v1.1.1

本版统一官网与桌面端的便签体验，改进收取、阅读、拖拽及 macOS 系统入口。

- 官网调整为紧凑介绍、交互桌面、使用场景和平台下载；放大周报草稿，完善手机、短屏、六语言及语言切换时的焦点反馈。
- macOS 与 Windows 共用当前便签样式，保留各自原生剪贴板、全局快捷键和跨应用拖放能力，不添加桌面教学引导。
- 收取内容后临时展示四秒，只有显式固定才保持展开；继续支持文字选取、反复收取、整卡拖拽、点击复制、方向键、Delete 和 Esc。
- 新增完整内容阅读入口：按钮或 Space 放大查看，Esc 返回便签，复制反馈保留在右下角。
- macOS 菜单栏图标和固定小点由系统统一适配明暗；关闭自动收取时变淡，菜单仍可使用。Dock 右键菜单增加展开、设置、自动收取和固定操作。
- 更新已确认的应用图标与六语言 README、截图和演示素材，修正旧 README 生成模板中的入口和下载地址。

| 下载包 | 适用系统 |
| --- | --- |
| `SnapSlot-1.1.1-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel |
| `SnapSlot-1.1.1-windows-x64-setup.exe` | Windows 10 1809+ / 11，x64 |

随附安装包校验值、清单、完整静态官网 ZIP 和六语言素材 ZIP。Windows 包含 .NET 运行时，缺少 WebView2 时由安装器从微软下载。

本地验收覆盖网页与共享桌面界面回归、61 项 macOS 实际宿主检查、34 项状态栏检查、23 项 Dock 菜单检查及发布、下载校验。网页键盘用例分别检查 Mac 和 Windows 外观，并等待系统外观初始化后操作。正式安装包由 GitHub Actions 从发布提交构建，并在公开 Release 前验证 Windows 安装、运行和卸载，以及网站和六语言媒体生成。

Mac 包为 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证；Windows 安装包未做代码签名。多显示器混合 DPI、所有外部应用的权限与物理拖放仍需补充实机覆盖。
