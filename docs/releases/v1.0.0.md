# SnapSlot v1.0.0

首个公开版本。复制的图片、选中的文字成为屏幕上沿的便签，点击重新复制，拖进文档或文件夹即可使用。

- macOS 和 Windows 使用与官网一致的便签界面，支持扇形展开、滚轮切换、固定、拖出与清空。
- 提供玻璃、纸张、石墨外观和六种语言，状态栏 / 托盘菜单包含设置、自动收取、固定和退出。
- 固定时状态图标显示圆点。便签仅保存在当前会话，最多 30 条，不需要账号，不上传内容。

| 下载包 | 适用系统 | 安装方式 |
| --- | --- | --- |
| `SnapSlot-1.0.0-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel | 打开 DMG，将 SnapSlot 拖入“应用程序” |
| `SnapSlot-1.0.0-windows-x64-setup.exe` | Windows 10 / 11 x64 | 双击 Setup 安装；安装后从桌面或开始菜单打开 |

官网直接提供安装包，GitHub Release 提供相同文件。`SHA256SUMS.txt` 和 `manifest.json` 用于校验下载完整性。

Mac 包使用 ad-hoc 签名，尚未取得 Developer ID 签名和 Apple 公证，Gatekeeper 可能阻止首次启动。选中文字功能需要辅助功能权限。Windows 包未做代码签名，已包含 .NET 运行时，缺少 [Microsoft Edge WebView2 Runtime](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution) 时会自动联网安装；请保持联网。支持从 Windows“已安装的应用”卸载。

本次本地验证包含 Mac 双架构编译及原生冒烟检查、Windows x64 自包含发布及逻辑检查、网站浏览器检查和下载 HTTP 检查。Windows 安装器的文件载荷已检查，安装与卸载检查已加入 Windows CI，需推送后运行；Windows 可视化行为仍需实机验收。
