# SnapSlot v1.1.4

这一版新增多项桌面端实用能力，并重点修复 Windows 顶部呼出稳定性、选字交互与独立悬浮窗打开速度。

- **桌面端效率增强**：新增快速记一句便签、放大预览内文字编辑与上一张/下一张切换、本地离线 OCR 文字识别（macOS Vision / Windows WinRT）、拖入顶部收为便签、独立悬浮便签（支持缩放与透明度调节）、开机自启、macOS Dock 显示开关、跨显示器共享会话与内容 SHA-256 去重，以及设置页手动检查更新。
- **Windows 顶部呼出修复**：将低级鼠标钩子事件改为异步派发并恢复 50ms 常驻顶边轮询，避免钩子超时失效或漏事件；适配高分屏（4K / 高 DPI）顶边容差并修正置顶与显示顺序。
- **无遮挡选字体验**：移除在便签和 OCR 识别结果中划选文字时弹出的“钉到顶上”浮动气泡，避免遮挡后续选字；继续支持使用自定义文字快捷键收取选中内容。
- **独立悬浮窗提速**：Windows 端为独立悬浮便签引入后台预热与关闭回收复用池，点击后直接呈现内容，大幅减少冷启动等待。

| 下载包 | 适用系统 |

| `SnapSlot-1.1.4-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel |

随附 SHA-256、记录实际签名及公证 submission ID 的安装包清单、完整静态官网与六语言媒体 ZIP。Mac 正式包使用 Developer ID 签名并经 Apple 公证；Windows 安装包包含 .NET 运行时，缺少 WebView2 时由安装器自动从微软下载（Windows 安装包未做代码签名）。

发布流水线在 GitHub runner 执行双端构建、Mac 公证与原生冒烟检查、Windows 安装和卸载验证、官网及共享界面回归，并刷新六语言媒体。证书或公证授权缺失、Apple 拒绝、验证失败时停止发布，不回退到临时签名，不覆盖历史版本。
