# SnapSlot v1.1.2

这一版补齐便签浏览时的位置提示，并调整 Windows 托盘图标和官网的默认下载选项。

- 多张便签时，在当前便签下方显示轻量的“当前位置 / 现有总数”。切换、收取和删除后同步更新；单张或空会话不显示，不增加按钮或遮挡便签。
- 官网演示和下载区共用系统识别：Windows 默认选择 Windows，Mac 默认选择 macOS。手动选择下载平台后，不因切换演示或调整窗口大小而覆盖选择。
- Windows 托盘从原图标的高分辨率帧取图，去掉重复缩入的透明留白，按系统小图标尺寸等比例绘制；保留暂停收取和固定便签的状态标记。
- 手机官网为位置索引与引导提示留出间距，保持文档区域与操作入口可用。

macOS Dock 菜单继续使用系统外观，其外侧阴影由 macOS 绘制。

| 下载包 | 适用系统 |
| --- | --- |
| `SnapSlot-1.1.2-macOS-universal.dmg` | macOS 13+，Apple Silicon / Intel |
| `SnapSlot-1.1.2-windows-x64-setup.exe` | Windows 10 1809+ / 11，x64 |

随附 SHA-256、安装包清单、完整静态官网与六语言媒体 ZIP。Windows 包含 .NET，缺少 WebView2 时由安装器从微软下载。

发布检查覆盖网页与共享界面回归、六语言与手机布局、Windows 图标边界和缩放逻辑、两端构建，以及 Windows 安装、原生界面启动和卸载。多显示器与微信等应用托盘图标的实际视觉对比仍以目标 Windows 设备为准。

Mac 包使用 ad-hoc 签名，尚未进行 Apple 公证；Windows 安装包未做代码签名。
